# Dog Breed Viewer

A simple, interactive web application that showcases different dog breeds. Users can click on breed buttons to view information about each breed along with their images.

## Project Structure

```
dogbreed/
├── index.html          # Main HTML file
├── style.css          # Styles for the website
├── script.js          # JavaScript for interactivity
├── README.md          # This file
├── landing.png        # Hero banner image
├── pitbull.jpg        # Pitbull breed image
├── labrador.jpg       # Labrador breed image
└── beagle.jpg         # Beagle breed image
```

## Features

- Interactive breed selection buttons
- Smooth transitions and animations
- Responsive design for all screen sizes
- Image gallery with breed descriptions
- Hover effects on buttons and breed cards
- Automatic scrolling to selected breed
- Mobile-friendly interface

## Setup and Running

1. Make sure you have Python installed on your system
2. Open a terminal/command prompt
3. Navigate to the project directory:
   ```bash
   cd path/to/dogbreed
   ```
4. Start the Python HTTP server:
   ```bash
   python -m http.server 8000 --bind 127.0.0.1
   ```
5. Open your web browser and visit:
   ```
   http://127.0.0.1:8000
   ```
